# Archive: original 50-page design

These five files (`page_055.txt`, `page_056.txt`, `page_057.txt`, `page_058.txt`, `page_060.txt`) are draft pages and a constraint-verification table from the **original 50-page construction** of *Partition du texte*.

The canonical instance in this deposit is the **46-page version** (see `../page_059.txt` and `source/`). These archived files are kept for historical/reproducibility reasons only. They are *not* part of the canonical graph, the canonical MIS, or `instances.csv`.

- `page_055.txt`–`page_058.txt`: the four extra pages (originally numbered 47–50) that were dropped when the text was canonicalised to 46 pages.
- `page_060.txt`: the constraint-verification table (`Pages per form: 10/10/10/10/10`) that applied to the 50-page design. The corresponding verification for the 46-page canonical instance is implicit in the 46 source files plus the canonical metadata.
