## Adjacency preservation

Each replacement keeps a token that registers the same kagome-anchor concept:
- "ash of suns" → "ember" / "soot" (combustion residue, dark warm light)
- "old light" → "late starlight" / "late light" (delayed photons)
- "stone-memory" → "millstone" / "worn flint" / "worn paving stone" / "worn groove" (durable lithic record)
- "dream-water" → "rain in the basin" / "rain-filled" / "rain in the lacquer bowl" (still water as reverie)
- "bell beneath the sea" → "buoy bell in fog" / "sunken anchor hum" (muffled marine resonance)
- "deep sky overhead" → "one cold star" / "one star, then nothing" / "gap between the eaves/boughs" / "moon-shadow" (vertical celestial register)
- "the unnamed" → "a shape past the lamp/door/wall" (uncanny near-presence)
- "first breath" → "white breath" (visible breath in cold air)
- "mountain time" → "the long ridge" / "the ridge in slow shadow" (slow geological register)
- "void" → "the gap between" (negative space made geometric)

The shared-anchor edge constraint (every kagome edge: ≥1 anchor in common) is
preserved at the *concept* level via these systematic substitutions; the embedder
cosine should still see the adjacencies. Surface uniqueness now reads as observed
imagery rather than a mechanism tag.
