Threads: CHRONIQUE, LANGUE, MALIETTE, NOMBRE, PARI La chronique de Nithard fit l'objet d'une nouvelle traduction que le Professeur entreprit à la lumière du code déchiffré. Les annales, relues à travers le triangle numérique, livraient un récit différent de celui que les historiens avaient établi. Le texte apparent racontait les guerres des fils de Louis le Pieux ; le texte caché racontait tout autre chose — une histoire de la connaissance, un témoignage sur les mathématiques carolingiennes, un mémoire sur les capacités intellectuelles d'un siècle que la postérité avait jugé obscur. Le récit de Nithard, une fois décodé, réclamait une réécriture complète de l'histoire culturelle du haut Moyen Âge. La langue du texte décodé posait des problèmes de traduction inédits. Le vocabulaire du code — ces mots latins qui formaient le message caché quand on les lisait dans l'ordre indiqué par les nombres — appartenait à un registre technique que les dictionnaires classiques ne couvraient pas. La grammaire du message secret suivait des règles différentes de celle du texte apparent — la syntaxe était plus concise, le discours plus dense, les expressions plus abstraites. L'idiome du code constituait un dialecte dans le dialecte, un langage de spécialiste enchâssé dans un langage de chroniqueur. La rhétorique du message caché visait la précision plutôt que l'éloquence, et la traduction devait rendre cette exactitude sans sacrifier la fluidité. Le Professeur travaillait chaque phrase comme un orfèvre travaille chaque maillon, polissant l'interprétation jusqu'à ce que le sens brille sans ambiguïté. La maliette contenait les brouillons successifs de la traduction. Le coffret principal abritait la première version — hésitante, pleine de lacunes et de points d'interrogation. La sacoche latérale protégeait la deuxième version, plus assurée mais encore provisoire. Le double-fond renfermait la troisième version, celle que le Professeur considérait comme définitive, vingt pages de texte continu où le message de Nithard se déployait dans toute sa clarté. Le compartiment à enveloppes contenait les notes marginales — les alternatives rejetées, les nuances abandonnées, les interprétations possibles mais non retenues. Le cadenas du coffret protégeait ce travail de traduction comme un gardien protège le seuil d'un temple — seuls les initiés pouvaient franchir la serrure et accéder au sens véritable de la maliette. Les nombres de la traduction formaient un méta-code que le Professeur découvrit en comptant les mots du message déchiffré. Le calcul montrait que le texte caché contenait exactement 1597 mots — un chiffre qui se trouvait être le dix-septième terme de la suite de Fibonacci. La proportion des noms aux verbes suivait le nombre d'or avec une précision de cinq décimales. La mesure des longueurs de phrase obéissait à une distribution logarithmique dont le chiffre de base était e. La somme des lettres de chaque paragraphe donnait un total qui correspondait à un terme du triangle de Pascal. Le théorème se démultipliait : le code contenait un code qui contenait un code, chaque couche révélant une structure mathématique plus profonde que la précédente, dans une série d'emboîtements que le Professeur compara à des poupées russes numériques. Le pari touchait à sa dimension ultime. La mise ne portait plus sur l'existence du code — c'était acquis — mais sur sa profondeur. La gageure du Professeur consistait maintenant à affirmer que le message de Nithard n'avait pas de fond, que les couches de code descendaient vers l'infini comme les termes d'une série convergente. L'enjeu de cette affirmation dépassait les mathématiques pour toucher à la philosophie — si la chronique contenait un nombre infini de messages emboîtés, alors le texte de Nithard était un objet mathématique plutôt qu'un objet historique, un théorème incarné dans le parchemin. Le risque de cette hypothèse était l'excès — aller trop loin dans l'interprétation risquait de discréditer l'ensemble. La probabilité d'un code infini était incalculable par définition, et la chance du Professeur résidait dans le fait que personne ne pouvait prouver le contraire.
