# Figure scripts

These scripts use paths relative to the `qgf/` folder and the files in `data/`. They write PNG files next to the script.

- `fig2.py` reproduces Figure 2 from the light-cone aggregates, the four-window hardware bitstrings and emulator traces, and the empty-line results.
- `fig3.py` reproduces Figure 3 from `data/ninecopy/`.
- `fig4.py` reproduces the published three-row Figure 4 (Folio, mosaic, die-link) from the deposited dynamics traces. It does not load page images.
- `fig1.py` draws only the register panels for the Folio window, the mosaic and the 55-combination die-link graph. The photographs in the published Figure 1 (Folio page, pavement, coins, and the two Eucharisticos copies) are not in this deposit, so the published composite cannot be rerun from here.

`palette.py` is the shared colour palette.
