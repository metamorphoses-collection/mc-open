# Supplement source

`supplement.tex` is a public copy of the Overleaf supplement, with two changes that were not applied to the Overleaf file:

- The sections “The pulled sort read with the two atoms beside it” and “Re-set lines on the 1579 page” have been removed, so the public deposit does not go beyond the derived Figure 3 measurements for the nine copies.
- Cross-references have been updated to the remaining sections: S1 objects, S2 mosaic generator, S3 bond-dimension, S4 synthetic cycle-parity, S5 readout-phase witness, S6 local addressing, S7 empty-line per-pair values, S8 die-link register, S9 device characterisation, S10 Fresnel campaigns.

A short objects-background paragraph in S1 still mentions the nine-copy collation, because that is how Figure 3 is introduced. The bond-dimension table still has a “side-note window” row from an earlier figure.

`si_fresnel.png` is a plot, not a photograph. `references.bib` is the paper bibliography, included so this file can be compiled with the paper's style files.
