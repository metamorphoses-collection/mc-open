# Orsini concordance

A concordance of the Roman Republican family coins in Fulvio Orsini's *Familiae Romanae* (Rome, 1577), linking each
coin Orsini describes to its modern reference (Crawford *RRC*, *RIC*, *RPC*, specialist catalogues), with Orsini's own
readings and notes.

| File | Format |
|---|---|
| `orsini_concordance.json` | full records |
| `orsini_concordance.jsonld` | linked data (JSON-LD) |
| `orsini_concordance.csv` | flat table |

**This is a mirror of release v2.0 (file update v2.0e, 9 Jul 2026).** The reference copy, with the 558 MB self-contained
HTML viewer and full release notes, is on Zenodo: version DOI [10.5281/zenodo.20754025](https://doi.org/10.5281/zenodo.20754025),
all versions [10.5281/zenodo.19355475](https://doi.org/10.5281/zenodo.19355475). Cite the Zenodo record. Files here are
byte-identical to the Zenodo files (md5: json a3ddfef4…, jsonld b037b0d7…, csv f9eb8ebb…).
